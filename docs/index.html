Novel Scraper

Client-side web novel downloader — NovelBin · FanMTL · NovelHall
ℹ️
This scraper runs entirely in your browser via a CORS proxy. It replicates the PHP scraper's pipeline: fetches metadata, builds the chapter list, downloads each chapter, cleans the content, and produces A5-optimised HTML files ready for download. Choose your proxy below; corsproxy.io is the default.
